# Customer-Churn-KPI
Built an end-to-end customer Churn analytics project for an OTT subscription dataset, analyzing 15+ KPIs. Identified a 28.6% overall churn rate, with monthly-contract customers showing a 55.6% churn rate compared to 8.3% for annual contracts, highlighting a key opportunity for contract-migration and retention strategies.

## 📊 Key Insights

### 1. Churn Rate

**28.57%** of customers have churned.

### 2. Retention Rate

**71.43%** of customers are retained by the company.

### 3. Churn by Plan Type

| Plan Type | Churn Rate |
| --------- | ---------: |
| Basic     |     60.00% |
| Standard  |     22.22% |
| Premium   |     14.29% |

**Insight:** The Basic Plan has the highest churn rate at **60.00%**, while the Premium Plan has the lowest churn rate at **14.29%**.

### 4. ARPU (Average Revenue Per User)

**Rs. 18.85**

On average, each customer generates **Rs. 18.85** in revenue.

### 5. Revenue at Risk

**Rs. 73.94K**

Approximately **Rs. 73.94K** in revenue is at risk due to customer churn.

### 6. Escalation Rate

**19.05%**

Approximately **19.05%** of customers had escalated complaints or issues.

### 7. Average Complaints Per User

**0.43**

On average, each customer has **0.43 complaints**.

### 8. Correlation Between Escalations and Churn

**0.77**

There is a **strong positive correlation** between customer escalations and churn.

### 9. Churn by Contract Type

| Contract Type | Churn Rate |
| ------------- | ---------: |
| Monthly       |     55.56% |
| Annual        |      8.33% |

**Insight:** Monthly-contract customers have a significantly higher churn rate (**55.56%**) compared with annual-contract customers (**8.33%**). This suggests that encouraging customers to move from monthly to annual contracts could help improve customer retention.
